# HPC R Examples - Array Jobs

This directory contains examples of using SLURM job arrays with R scripts.

## Basic Array Example (`bs_array.R`, `bs_array.slurm`)

This example demonstrates a fundamental SLURM job array setup.

*   **`bs_array.R`**: An R script that performs a bootstrap analysis.
    *   It takes the `SLURM_ARRAY_TASK_ID` environment variable to differentiate tasks.
    *   Each task generates sample data, performs a number of bootstrap replications, and calculates the mean.
    *   Results (task ID, iteration, mean) are saved to a CSV file in an `output/<SLURM_ARRAY_JOB_ID>` directory (e.g., `output/19329543/bootstrap_results_1.csv`).
    *   A summary (job ID, task ID, number of iterations, mean of means, 95% CI, runtime) is saved to a text file in a `summary/<SLURM_ARRAY_JOB_ID>` directory (e.g., `summary/19329543/bootstrap_summary_1.txt`).
*   **`bs_array.slurm`**: A SLURM batch script to run the `bs_array.R` script as a job array.
    *   `#SBATCH --array=1-10` defines an array of 10 tasks.
    *   It creates log directories and navigates to the script's directory before execution.
    *   It loads an R module and runs the R script using `Rscript --vanilla bs_array.R`.

**To Run:**

```bash
sbatch bs_array.slurm
```

## Reading Parameters from CSV Example (`read_from_csv/`)

This example illustrates how to supply different parameters to each task in a SLURM job array by reading them from a CSV file.

*   **`read_from_csv/vars_from_csv.R`**: An R script designed to accept `--sigma` and `--beta_mag` as command-line arguments.
    *   It performs calculations based on these parameters.
    *   It uses `Sys.getenv("SLURM_ARRAY_TASK_ID")` for unique seeding and file naming.
    *   Results are saved to a CSV file named `results_task_<SLURM_ARRAY_TASK_ID>.csv` within an `output/<SLURM_ARRAY_JOB_ID>` directory.
*   **`read_from_csv/params.csv`**: A CSV file where each line contains parameters for a corresponding task in the job array. For example:
    ```csv
    0.01,0.5
    0.02,0.7
    0.005,1.2
    ```
*   **`read_from_csv/vars_from_csv.slurm`**: A SLURM batch script that:
    *   Defines a job array (e.g., `#SBATCH --array=1-3`).
    *   For each task, it reads the corresponding line from `params.csv` using `sed`.
    *   It extracts the `sigma` and `beta_mag` values from the line.
    *   It then executes `vars_from_csv.R`, passing the extracted parameters as command-line arguments.

**To Run:**

Navigate to the `read_from_csv` directory and submit the job:

```bash
cd read_from_csv
sbatch vars_from_csv.slurm
```

## Combine CSV Example (`combine/`)

This example provides a way to aggregate results from multiple CSV files, typically generated by a preceding job array (like the `bs_array` example).

*   **`combine/combine_csv.R`**: An R script that:
    *   Checks for and installs required packages (`dplyr`, `readr`) if missing.
    *   Identifies the directory containing the CSV files to be combined. It can:
        *   Use the `ARRAY_JOB_ID` environment variable (if set when submitting the combine job) to specify the output directory of the array job.
        *   Automatically find the most recently modified directory in `../output/` if `ARRAY_JOB_ID` is not set or the specified directory doesn't exist.
    *   Lists all files matching the pattern `bootstrap_results_*.csv` in the identified directory.
    *   Reads and combines these CSV files into a single data frame.
    *   Saves the combined data to a new CSV file named `combined_data.csv` within a `combined` subdirectory of the input data directory (e.g., `../output/<ARRAY_JOB_ID>/combined/combined_data.csv`).
*   **`combine/combine_csv.slurm`**: A SLURM batch script to run the `combine_csv.R` script.
    *   It loads the `Rtidyverse` module.
    *   It executes the R script. You can optionally pass the job ID of the array whose results you want to combine by setting the `ARRAY_JOB_ID` environment variable when submitting this job.

**To Run:**

Navigate to the `combine` directory. To combine results from a specific array job (e.g., job ID 19329543):

```bash
cd combine
sbatch --export=ARRAY_JOB_ID=19329543 combine_csv.slurm
```

If you want it to attempt to find the latest job's output automatically:

```bash
cd combine
sbatch combine_csv.slurm
```
